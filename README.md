# Machine Learning Classification Projects

A collection of three Jupyter Notebook projects exploring different machine learning classification techniques using Python and Scikit-learn.

## Projects

### 1. Higgs Boson Signal Classification
Binary classification of particle physics data to distinguish Higgs boson signals from background events.

### 2. Sign MNIST Classification
Classification of American Sign Language hand gestures using image data.

### 3. Wine Classification & Model Selection
Multiclass classification of wine samples, focusing on comparing and selecting machine learning models.

## Tools & Technologies
Python · Scikit-learn · Pandas · NumPy · Matplotlib · Google Colab

## Goal
Practice data preprocessing, model training, evaluation, and classification techniques through hands-on projects.
